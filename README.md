# Weather App

- приложение, которое при вводе города, показывает погоду в этом городе

## Функционал

- поиск по городу
- получение сведений о погоде
- отображение температуры, влажности, ветра
- сохранение последнего города в localStorage
- обработка ошибок — если город не найден

## Стек

HTML5, CSS3, TypeScript, React, CSS Modules, OpenWeatherMap API

## Инструкция по запуску
Клонировать репозиторий:
```bash
git clone https://github.com/albina-sar/weather-app.git
```

Установить зависимости:
```bash
npm install
```

Создать файл .env в корне проекта:

```env
VITE_API_KEY=
```

Файл .env добавлен в .gitignore — токен не попадает в репозиторий.

Запустить проект:
```bash
npm run dev
```

## Как работает получение данных (API)
в приложении используется API OpenWeatherMap, Endpoint - (/data/2.5/weather), для поиска конкретного города отправляет q=${city}, ключ API - appid=${API_KEY}, для получения данных в метрической системе отправляет units=metric, для получения данных на русском языке - lang=ru. В ответ получает город, страну, погоду, температуру, влажность, ветер и давление. Информация обрабатывается через getWeather(city) в api/weather.ts.
